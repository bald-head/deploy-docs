## 检查什么

PreToolUse 在 Agent 调用安装器 matcher 覆盖的写入或命令工具前运行。它可以拒绝高置信度破坏性命令，以及活动工作流不允许的写入；拒绝原因通过客户端返回给 Agent。

| 检查 | 当前行为 |
|---|---|
| 高风险命令 | 拒绝广泛目标的递归强制删除、强制推送或删除远端 ref、丢弃工作区状态、清库等命令 |
| 工作流阶段 | 规划未完成、等待确认或阻塞时，拒绝不符合当前阶段的生产写入 |
| TODO 直接写入 | 活动工作流中，拒绝直接编辑 TODO，要求通过状态机原子修改 |
| 提交署名 | 拒绝源码规则列出的 AI 协作者或自动生成署名元数据 |
| 配置和凭据 | 可选的非阻断提醒，不替代当前请求授权 |

安装器当前 matcher 覆盖 `Bash`、`Write`、`Edit`、`MultiEdit`、`NotebookEdit`、`exec_command`、`apply_patch` 及相应封装工具名。具体是否触发，仍取决于客户端实际发出的工具事件。

## 命令防护

防护分析命令文本、参数和目标范围。递归删除当前工作目录、用户主目录或文件系统根目录属于广泛目标；删除一个明确的子目录不等于已被用户授权，只是未必命中这项高置信度规则。

Git 防护还识别聚合短选项、Shell 包装和 refspec，不能通过改写命令外形避开远端历史改写检查。数据库防护针对源码列出的清库、清表和数据库客户端命令模式，不是完整的 SQL 解析器。

<Aside type="caution">
Hook 的放行只表示未命中当前规则，不是安全证明，也不增加授权。实际执行前仍需明确目标、影响和已有授权。
</Aside>

### 不执行目标命令的检查

不要在真实工作区试跑危险命令来检查 Hook。脚本导出的判定函数接收命令字符串并返回判定，不执行该字符串：

```bash
node -e 'const guard = require(process.argv[1]); console.log(guard.dangerousCommandReason("pwd", process.cwd()) || "未命中危险命令规则")' "<skills-root>/runtime-hooks/scripts/pre-tool-use.cjs"
```

这个例子只检查 `pwd` 文本。需要核对某条被拒绝的命令时，结合 Hook 返回原因读取 `dangerousCommandReason`、`findBroadRecursiveDelete` 或 `forcePushAssessment` 的对应规则。

## 工作流门禁

当唯一 TODO 含活动流程状态机时，`workflowWriteGate` 会读取当前阶段、状态和执行实例：

| 当前阶段或状态 | 写入边界 |
|---|---|
| 业务开发之前 | 允许只读调查和适用规划文档，禁止生产写入 |
| `awaiting-user` 或 `blocked` | 先完成确认或恢复，不直接继续生产写入 |
| 业务开发至验收 | 当前实例已领取 Feature 且状态有效时可实施 |
| `git-delivery` | 允许状态核验和已授权 Git 交付，不再编辑生产文件 |
| 无活动工作流 | 该阶段门禁不生效，仍执行适用命令检查 |

阶段错误时，先核对原始 TODO、已有用户授权和阶段产物。结论已经齐全就通过状态机推进；确有需求或技术决定缺失时，先完成对应决定。

## 写集由谁核验

并行写集由 TODO 状态机在解析、领取和完成检查时核验，主 Agent 收口时还要对照实际 diff。当前 PreToolUse 没有逐文件比对 `parallelWriteSet` 的通用写入锁，因此不能保证越界文件一定被工具层拒绝。

写集发生真实变化时，先确认当前 Feature 的目标和交付边界，再定向调整 TODO。共享路由、配置、迁移或契约应有唯一 Owner，或按依赖串行完成；不能仅从声明里删除仍要修改的文件来规避冲突。

## 测试与配置边界

测试源码只在用户本轮明确要求新增或修改测试时编辑。运行现有测试或一次真实主路径验证不需要先生成测试；高风险、覆盖率、CI 和 Review finding 不会自动授予测试源码权限。这是实施规则，不能把 PreToolUse 未拒绝某次编辑当作授权证据。

当前安装器使用 `--skip-credential-checks`。脚本中的凭据和配置提示即使开启也不阻断已授权范围；配置值来源和各环境差异仍按本轮请求与仓库事实处理，不应把真实值写进日志或无关文档。

## 开关

| 环境变量 | 实际作用 |
|---|---|
| `AGENT_RUNTIME_HOOKS_DISABLED=1` | 跳过本页 PreToolUse、SessionStart 和提示音；上下文和 TODO 脚本仍可能运行 |
| `AGENT_COMMAND_GUARD=0` | 跳过整个 PreToolUse，包含其流程写入门禁 |
| `AGENT_RUNTIME_WARNINGS=1` | 开启脚本内的非阻断提醒 |

环境变量须在启动客户端前设置。对被执行命令设置行内环境变量，不会改变已经运行的 Hook 进程环境。排障时优先核对拒绝原因和实际阶段，不用关闭防护替代问题修复。
