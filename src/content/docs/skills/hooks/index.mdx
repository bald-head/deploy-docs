## 概述

Runtime Hooks 在客户端的关键事件中注入行为准则和项目事实、提醒当前 TODO、检查部分高风险命令，并在回复结束或需要人工接续时播放提示音。它们辅助 Agent 执行已授权的任务，不能替代 Skill 正文、真实验证或 Git 交付。

Hook 随 Skills 仓库分发，位于 `<skills-root>/runtime-hooks/`。首次安装见 [安装与配置](/skills/getting-started/)，Hook 配置细节见 [Hook 安装指南](/skills/hooks/installation/)。

## 事件分工

| 事件 | 触发时机 | 当前职责 | 详细文档 |
|---|---|---|---|
| SessionStart | 会话启动 | 自检托管配置、按设置修复；只读 Penpot 本地注册状态 | [查看](/skills/hooks/session-start/) |
| UserPromptSubmit | 提交提示词 | 注入行为内核、记忆摘要、开发者范围和当前 TODO 提醒 | [查看](/skills/hooks/user-prompt-submit/) |
| PreToolUse | matcher 覆盖的命令或写入工具前 | 拒绝命中规则的危险命令；检查活动流程写入阶段 | [查看](/skills/hooks/pre-tool-use/) |
| SubagentStart | 子 Agent 启动 | 复用项目上下文注入 | [查看](/skills/hooks/subagent-start/) |
| SubagentStop | 子 Agent 停止 | 已领取 Feature 时校验 Handoff，按当前 TODO 状态处理 | [查看](/skills/hooks/subagent-stop/) |
| Stop | 主 Agent 回合停止 | 完成门禁、原子准备 TODO 状态、远端核验和续作提示 | [查看](/skills/hooks/stop/) |
| PermissionRequest | Claude Code 请求授权 | 播放确认提示音 | [查看](/skills/hooks/notification/) |

两端事件集合不同。`PermissionRequest` 是 Claude Code 事件，Codex 通知使用用户级 `config.toml` 的 `notify` 通道，不能据此断言 Codex 已注册同名 Hook。配置对照见 [Hook 故障排查](/skills/hooks/troubleshooting/)。

## 每轮上下文

注入包含跨客户端行为内核、与当前问题相关的稳定项目事实、开发者归属范围和当前 TODO 的有界提醒。存在本地场景匹配时，还可带入候选 Skill 提示。

<Aside type="note">
完整 Skill 清单由 Harness 原生发现提供，命中后按需读取 `SKILL.md`。本地路由提示不代表实际调用，不执行 frontmatter 中的 `gates` 或后续 Skill 链。
</Aside>

项目记忆按根目录 `PROJECT-MEMORY.md`、`docs/PROJECT-MEMORY.md`、`docs/project-memory.md` 的顺序复用。都没有时才在根目录创建模板；空章节提示由 `init-docs` 采集事实，再通过 `project-details` 归并。上下文有预算上限，截断时直接读取相关源章节。

## TODO 与 Git

TODO 状态机负责领取、依赖与并行写集检查、完成门禁、原子状态切换及远端核验。一个实例同一时刻只能拥有一个 `[~]`，一个 Feature 也只能由一个实例领取。

首次 commit 前，状态机把当前 Feature 准备为 `[x]`。主 Agent 再把真实功能改动、必要契约和 TODO hunk 同次 commit & push。Stop Hook 不执行 Git 提交或推送；远端核验前的本地完成会显示 `delivery-pending`，不能解锁依赖它的下一项。

## 命令与写入检查

PreToolUse 可拒绝命中规则的广泛递归删除、强制推送或删除远端 ref、丢弃工作区状态、清空数据库和根目录权限改写。放行表示没有命中当前规则，不是安全或授权证明。

活动工作流进入 `business-development` 前，生产写入受阶段门禁限制。并行写集由 TODO 状态机核验，实际 diff 仍由 Agent 收口对账；当前 PreToolUse 不是逐文件写集锁。

验证安装时不应在真实工作区执行危险命令。只检查命令字符串的方法见 [PreToolUse Hook](/skills/hooks/pre-tool-use/#不执行目标命令的检查)。

## 安装检查

```bash
node "<skills-root>/runtime-hooks/scripts/install.mjs" --check --json
```

本地检查通过以 `installed: true` 且 `needsInstall: false` 为准。Claude Code 安装后重启会话；Codex 通过 `/hooks` 检查并信任新的定义。

## 环境变量

| 变量 | 实际作用 |
|---|---|
| `AGENT_RUNTIME_HOOKS_DISABLED=1` | 停用 SessionStart、PreToolUse 和提示音；不关闭上下文注入或 TODO 脚本 |
| `AGENT_COMMAND_GUARD=0` | 停用整个 PreToolUse，包含其流程写入门禁 |
| `AGENT_RUNTIME_HOOKS_AUTO_UPDATE=0` | 启动时仍检查差异，但不自动改配置 |
| `AGENT_RUNTIME_WARNINGS=1` | 开启非阻断风险提醒 |
| `AGENT_COMPLETION_SOUND=0` | 关闭提示音 |
| `AGENT_DEVELOPER_NAME` | Git identity 与系统登录用户名都不可用时兜底 |
| `AGENT_TODO_DIR` | 只允许指向当前开发者的规范 TODO 目录 |
| `AGENT_RUNTIME_INSTANCE_ID` | Harness 未提供实例 ID 时兜底 |
| `CLAUDE_CONFIG_DIR` / `CODEX_HOME` | 指定对应客户端配置目录 |

环境变量需要由客户端启动时继承。要移除托管事件，按安装页核对具体条目和备份，保留第三方 Hook 与通知。

## 提示音

通知脚本区分确认、普通回复和任务完成。不可见标记只用于选择提示音，不能替代实际完成证据；详见 [中文语音通知](/skills/hooks/notification/)。
