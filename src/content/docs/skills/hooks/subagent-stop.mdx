## 交接检查

SubagentStop 与 Stop 共用 `todo-continuation.cjs`。当当前实例已领取一个 Feature 时，SubagentStop 分支检查最后回复中的交接字段；缺失时返回补充提示，齐全时允许主 Agent 接手收口。

主 Agent 负责对账实际 diff、统一验证与 Review，以及已授权的 commit & push。交接不是完成证明，也不能替代唯一 TODO 的原子状态切换或远端核验。

<Aside type="note">
Hook 的具体行为取决于当前 TODO 状态。共享脚本在无当前项时仍可能走状态协调或领取分支，因此委派前应明确当前 Feature 和 runtime instance，不能仅靠事件名称推断它完全不触碰状态。
</Aside>

## 必需字段

当前解析器读取行首字段，并要求值写在同一行。不要给字段名加 Markdown 粗体，也不要把值只放在下一行列表中。

| 字段 | 要求 |
|---|---|
| `Feature` | 与当前领取的 Feature ID 一致 |
| `Instance` | 与当前 runtime instance 一致 |
| `Changed files` | 实际修改路径；没有改动时明确写无 |
| `AC covered` | 覆盖的 AC，明确未完成项 |
| `Commands/evidence` | 已运行命令和实际观察结果 |
| `Decisions` | 已确定的实现取舍或复用结论 |
| `Unresolved risks` | 剩余风险；没有时写无 |

可在七行摘要之后补必要细节。以下是格式示例，内容必须替换为实际结果：

```text
Feature: USER-LOGIN
Instance: subagent-789
Changed files: src/api/user/login.ts, src/pages/login.vue
AC covered: AC-001 -> 登录主路径通过；AC-002 -> 错误提示通过
Commands/evidence: 现有构建通过；实际页面完成登录和失败提示验证
Decisions: 复用仓库已有认证 API 和表单组件
Unresolved risks: 无
```

## 未完成时怎么交接

阻塞或部分完成也应提供全部字段，并如实说明未验证、未实现或需要主 Agent 处理的部分：

```text
Feature: USER-LOGIN
Instance: subagent-789
Changed files: src/pages/login.vue
AC covered: AC-001 -> 表单完成；AC-002 -> 未验证，接口环境不可用
Commands/evidence: 页面构建通过；未完成真实登录
Decisions: 沿用已确认的接口契约
Unresolved risks: 等待认证服务环境恢复，恢复后需完成真实登录验证
```

不得把缺失验证改写成“通过”，也不应为交接建立新的状态文件。

## 主 Agent 收口

1. 对账交接中的路径、当前 Feature 写集和实际 diff，保留其他实例的无关改动。
2. 复用已有验证证据，按当前功能补齐缺口，并完成一次完整 `code-review`。
3. 首次 commit 前由状态机准备 TODO 的 `[x]` hunk。
4. 在已有授权内，将功能改动、必要契约和 TODO hunk 同次 commit & push。
5. 远端核验通过后，再领取依赖满足且写集互斥的下一项。

详细状态与 Git 边界见 [Stop Hook](/skills/hooks/stop/)。主 Agent 收口时不用机械重跑子 Agent 已完成且仍适用的每条检查。

## 常见问题

### 字段齐全仍提示缺失

检查字段是否写在行首、字段名是否被粗体符号包裹、冒号后是否有同一行值，以及 `Feature`、`Instance` 是否与当前领取记录一致。上面的纯文本格式可被当前解析器识别。

### 没有交接检查

先读取安装状态和当前 TODO。事件未注册、客户端未加载或当前实例没有拥有 Feature，都会影响分支选择：

```bash
node "<skills-root>/runtime-hooks/scripts/install.mjs" --check --json
```

安装或重新加载步骤见 [安装指南](/skills/hooks/installation/)。

### 交接与 diff 不符

让子 Agent 说明差异对应的真实改动和归属。必要的范围变化先更新当前 Feature 边界；无关的既有改动不擅自回退，也不混入当前功能提交。

## 环境变量

`AGENT_RUNTIME_HOOKS_DISABLED=1` 不会关闭 `todo-continuation.cjs`，不能用它推断 Handoff 检查已停用。需要调整事件时，先按安装页核对客户端托管配置。
