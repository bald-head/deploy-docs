## 最低优先级兜底

| Skill | 用途与边界 |
| --- | --- |
| [universal-development](/skills/skills-reference/low/universal-development/) | 仅在没有适用专业 Skill 时作为最低优先级兜底；不得替代 API、数据库、前端或安全能力。 |

优先检查是否有对口专业 Skill 或 `dev`。只有确实没有适用能力时才使用兜底，不能用它跳过 API、数据库、前端、安全等专业规则。
