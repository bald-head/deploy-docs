## 这一层是什么

Low 优先级的 38 个 Skill 是**扩展能力**：文件处理、设计工具、第三方集成、提示词工程、本机操作，以及没有专业 Skill 可用时的兜底。

优先级低不代表质量低，只代表**不该被模糊的话术抢先触发**。这些 Skill 通常需要你说得更具体一点，例如"把这份 Excel 拆成三个 sheet""生成一个雪花 ID 工具类"。

<Aside type="tip">
每个 Skill 的完整说明在 [Skill 参考手册](/skills/skills-reference/)；本页只做速查和选型。
</Aside>

## 兜底与代码生成（2 个）

| Skill | 什么时候用 | 说明 |
|---|---|---|
| [universal-development](/skills/skills-reference/low/universal-development/) | 扫完清单确实没有对口 Skill | 最低优先级兜底，不替代 API、数据库、前端或安全能力 |
| [code-generator](/skills/skills-reference/low/code-generator/) | 要模板、脚手架、代码生成器 | 通用生成器与模板；完整业务 CRUD 用 crud-development |

<Aside type="caution">
`universal-development` 是**最后手段**。如果它被触发了，通常说明触发词太模糊，或者确实缺一个专业 Skill——后者值得用 skill-creator 补上。
</Aside>
