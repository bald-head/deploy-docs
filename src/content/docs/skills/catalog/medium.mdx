## 项目、任务与历史会话

| Skill | 用途与边界 |
| --- | --- |
| [project-navigator](/skills/skills-reference/medium/project-navigator/) | 定位项目结构、入口、模块、组件和参考实现。 |
| [init-docs](/skills/skills-reference/medium/init-docs/) | 按真实交付需要初始化最少团队共享文档；项目记忆缺失或为空时协助采集事实并填充唯一 PROJECT-MEMORY.md。 |
| [next](/skills/skills-reference/medium/next/) | 根据当前开发者唯一 TODO、依赖和代码事实选择下一项可执行的完整功能。 |
| [progress](/skills/skills-reference/medium/progress/) | 只读统计当前开发者唯一 TODO 的功能进度 |
| [update-status](/skills/skills-reference/medium/update-status/) | 按代码、Review 和 Git 事实直接更新当前开发者覆盖完整交付面的唯一 TODO；不生成状态产物。 |
| [add-todo](/skills/skills-reference/medium/add-todo/) | 向当前开发者唯一 TODO 追加去重、可验收且保持纵向完整的功能或步骤。 |
| [resume-claude](/skills/skills-reference/medium/resume-claude/) | 读取并接续 Claude Code 历史会话，支持会话 ID、日志路径、描述或当前目录最近会话。 用户要求“读取 ClaudeCode 会话”“继续 Claude 会话”或从 Claude 切换后续作时使用； 只读总结不改代码，单纯继续当前 TODO 不触发。 |
| [resume-codex](/skills/skills-reference/medium/resume-codex/) | 读取并接续 Codex CLI 或 VS Code 历史会话，支持会话 ID、rollout 路径、描述或当前目录最近会话。 用户要求“读取 Codex 会话”“继续 Codex 上次任务”或从 Codex 切换后续作时使用； 只读总结不改代码，单纯继续当前 TODO 不触发。 |

两个 resume Skill 按历史来源选择，与当前运行客户端无关。只继续当前 TODO 使用 `next`；只总结历史时不进入实现。完整示例见[历史会话接续](/skills/usage/session-resume/)。

## 质量、性能与测试

| Skill | 用途与边界 |
| --- | --- |
| [check](/skills/skills-reference/medium/check/) | 按目标仓库已证明的后端规范检查实现；完整 diff 的缺陷与交付审查使用 code-review。 |
| [performance-doctor](/skills/skills-reference/medium/performance-doctor/) | 按运行指标排查并优化接口、SQL、页面加载、CPU 和内存性能；催促开发进度不触发性能诊断。 |
| [test-strategy](/skills/skills-reference/medium/test-strategy/) | 仅在用户本轮明确要求设计测试方案、策略或用例时使用；普通验证不触发，方案设计不授权修改测试源码。 |
| [test-development](/skills/skills-reference/medium/test-development/) | 仅在用户本轮明确要求写、补或修改测试源码时实施最小测试代码；运行测试、分析失败或查看覆盖率不触发。 |
| [real-browser-automation](/skills/skills-reference/medium/real-browser-automation/) | 根据用户的真实业务或测试提示词，使用真实 Chromium/Chrome 执行可追溯的端到端浏览器测试，实际完成点击、导航、登录、填写、校验、提交、查询、编辑、审批、上传等页面操作，并核对 SSE/API 响应、控制台错误、页面状态和截图证据。用户要求真实浏览器、浏览器自动化、Playwright、CDP、业务流程验证、页面回归、登录测试或前端接口联调时使用；不要用纯 HTTP 请求或只读 DOM 检查冒充业务测试。 |

运行已有检查不等于编写测试。`test-strategy` 处理本轮明确要求的测试方案，`test-development` 处理本轮明确要求的测试源码；两者的授权范围不同。
