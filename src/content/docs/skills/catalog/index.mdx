## Skill 分类

Skills Framework 包含 95 个专业 Skill，按 frontmatter 声明的优先级分为：

- **Critical**（2 个）：`change-impact-analysis`、`product-manager`
- **High**（25 个）：核心开发流程
- **Medium**（30 个）：专业领域能力
- **Low**（38 个）：扩展能力与兜底

优先级只影响**路由抢占顺序**，不代表能力强弱：优先级高的 Skill 会在话术模糊时先被选中，优先级低的需要你说得更具体。

## 使用建议

### 1. 优先使用高优先级 Skill

高优先级 Skill 经过深度优化，触发词丰富，路由准确率高。

### 2. 明确触发词

使用明确的触发词，避免歧义：

```
✅ "审查这段代码"（明确触发 code-review）
❌ "看一下这个"（不明确）
```

### 3. 按流程推进

遵循推荐的流程顺序：

```
product-manager → architecture-design → tech-decision → project-manager → 实施
```

### 4. 利用相关 Skill

查看 Skill 的 `related_skills`，了解前置和后续 Skill：

```
product-manager:
  before: [task-todo-workflow]
  after: [architecture-design, tech-decision, project-manager]
  complement: [brainstorm, grilling]
```
