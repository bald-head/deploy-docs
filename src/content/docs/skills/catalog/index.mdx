先按要做的事选择入口；已经知道名称时，直接查[参考手册](/skills/skills-reference/)或使用站点搜索。本站目录以 Skill 源仓库的 `SKILLS.md` 和各 `SKILL.md` 为依据，不包含客户端系统 Skill。

## 按任务查找

| 你要做什么 | 主要入口 | 操作指南 |
| --- | --- | --- |
| 了解一个项目、定位代码 | `start`、`project-navigator`、`project-details` | [快速上手](/skills/quickstart/) |
| 定义新项目或新功能 | `product-manager` 与规划、设计和技术能力 | [新项目开始](/skills/usage/new-project/) |
| 实施已批准功能 | 对口专业 Skill、`dev`；标准 CRUD 使用 `crud-development` | [功能开发流程](/skills/usage/feature-development/) |
| 读取或接续历史会话 | `resume-claude`、`resume-codex`，按历史来源选择 | [历史会话接续](/skills/usage/session-resume/) |
| 继续当前 TODO | `next` 选择任务，`progress` 查看进度 | [TODO 管理](/skills/usage/todo-management/) |
| 排查故障 | `bug-detective` 与对口实现能力 | [Bug 修复流程](/skills/usage/bug-fix/) |
| 调整已批准范围 | `change-impact-analysis` | [需求变更处理](/skills/usage/requirement-change/) |
| 审查已收敛的 diff | `code-review` | [代码审查流程](/skills/usage/code-review/) |
| 改善已有页面布局或交互 | `frontend-polish` | [参考页](/skills/skills-reference/high/frontend-polish/) |
| 定位接口或页面加载耗时 | `performance-doctor` | [参考页](/skills/skills-reference/medium/performance-doctor/) |
| 设计测试方案 | `test-strategy`，本轮明确要求方案时 | [参考页](/skills/skills-reference/medium/test-strategy/) |
| 编写测试源码 | `test-development`，本轮明确要求写或改测试时 | [参考页](/skills/skills-reference/medium/test-development/) |
| 提交、推送或处理分支 | `git-commit`、`git-workflow`，按授权范围 | [Git 操作指南](/skills/usage/git-workflow/) |
| 创建、优化或接入 Skill | `skill-creator`、`skill-optimizer`、`add-skill` | [安装与配置](/skills/getting-started/) |

这些入口是职责指引，不是固定调用链。请求的上下文、排除条件和当前任务范围比某个词是否出现更重要。

## 按优先级浏览

| 分组 | 数量 | 内容 |
| --- | --- | --- |
| [Critical 与 High](/skills/catalog/critical-high/) | 2 + 25 | 产品与范围、项目事实、设计与技术、纵向实现、质量和 Git |
| [Medium](/skills/catalog/medium/) | 32 | 任务与会话、基础设施、测试、文档与 Skill 管理 |
| [Low 与兜底](/skills/catalog/low-fallback/) | 38 | 文件、设计、工具、第三方集成与最低优先级兜底 |
| 合计 | **97** | 每个 Skill 对应一个独立参考页 |

分类来自 frontmatter 的 `priority`。它不代表能力强弱，也不保证客户端固定评分或抢占；实际选择依赖 Harness 原生发现结果和任务语义。兜底职责属于 `universal-development`，不额外增加一组数量。

## 本次新增的会话能力

- [`resume-claude`](/skills/skills-reference/medium/resume-claude/)：读取 Claude Code 历史，在当前客户端总结或继续。
- [`resume-codex`](/skills/skills-reference/medium/resume-codex/)：读取 Codex CLI、VS Code 历史，在当前客户端总结或继续。

支持 ID、记录路径、描述和当前目录最近会话；只读总结、当前 TODO 续作与历史任务接续的区别，见[历史会话接续](/skills/usage/session-resume/)。

## 如何维护目录

新增 Skill 时，同步所属分类、独立参考页、[参考手册索引](/skills/skills-reference/)以及适用的使用指南。涉及总数变化时也同步文档首页与主题 badge。文档排序使用 Starlight 的 `sidebar.order`，页面地址保持稳定。
