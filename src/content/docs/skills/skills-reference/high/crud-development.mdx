## 概述

`crud-development` 是 **High 优先级** Skill，负责手工实现完整的 CRUD 纵向业务切片，覆盖数据模型、API、Service 与页面联动。

**适用场景**：
- 手工实现 CRUD 业务功能
- 需要完整的前后端联动
- 已完成技术选型和数据库设计

**不适用场景**：
- 调用代码生成器 → 使用 `crud`
- 复杂业务逻辑 → 使用 `dev` 或 `universal-development`
- 专业领域（认证/缓存）→ 使用对应专业 Skill

## 使用示例

### 场景 1：实现用户管理 CRUD

**TODO 中的功能**：
```markdown
- [ ] `USER-MANAGE` 用户管理；Owner: alice-chen
  - 来源: PRD#用户管理
  - 目标: 管理员可以增删改查用户
  - 验收:
    - AC-001: 可以查询用户列表（分页）
    - AC-002: 可以新增用户
    - AC-003: 可以编辑用户信息
    - AC-004: 可以删除用户
  - 交付面: data / api / backend / web
```

**实施步骤**：

1. **数据模型**：
   ```java
   // src/main/java/entity/UserEntity.java
   @Entity
   @Table(name = "users")
   public class UserEntity {
       @Id
       private Long id;
       private String username;
       private String email;
       private String phone;
       private Integer status;
       private LocalDateTime createTime;
       private LocalDateTime updateTime;
   }
   ```

2. **数据访问**：
   ```java
   // src/main/java/mapper/UserMapper.java
   @Mapper
   public interface UserMapper {
       List<UserEntity> selectPage(UserQuery query);
       UserEntity selectById(Long id);
       int insert(UserEntity user);
       int updateById(UserEntity user);
       int deleteById(Long id);
   }
   ```

3. **业务逻辑**：
   ```java
   // src/main/java/service/UserService.java
   @Service
   public class UserService {
       @Autowired
       private UserMapper userMapper;
       
       public PageResult<UserVO> list(UserQuery query) {
           List<UserEntity> list = userMapper.selectPage(query);
           return PageResult.of(list);
       }
       
       public UserVO getById(Long id) {
           UserEntity entity = userMapper.selectById(id);
           return convert(entity);
       }
       
       public void create(UserDTO dto) {
           UserEntity entity = convert(dto);
           userMapper.insert(entity);
       }
       
       public void update(Long id, UserDTO dto) {
           UserEntity entity = convert(dto);
           entity.setId(id);
           userMapper.updateById(entity);
       }
       
       public void delete(Long id) {
           userMapper.deleteById(id);
       }
   }
   ```

4. **API 接口**：
   ```java
   // src/main/java/controller/UserController.java
   @RestController
   @RequestMapping("/api/v1/users")
   public class UserController {
       @Autowired
       private UserService userService;
       
       @GetMapping
       public Result<PageResult<UserVO>> list(UserQuery query) {
           return Result.ok(userService.list(query));
       }
       
       @GetMapping("/{id}")
       public Result<UserVO> getById(@PathVariable Long id) {
           return Result.ok(userService.getById(id));
       }
       
       @PostMapping
       public Result<Void> create(@RequestBody UserDTO dto) {
           userService.create(dto);
           return Result.ok();
       }
       
       @PutMapping("/{id}")
       public Result<Void> update(@PathVariable Long id, @RequestBody UserDTO dto) {
           userService.update(id, dto);
           return Result.ok();
       }
       
       @DeleteMapping("/{id}")
       public Result<Void> delete(@PathVariable Long id) {
           userService.delete(id);
           return Result.ok();
       }
   }
   ```

5. **前端页面**：
   ```vue
   <!-- src/pages/user/list.vue -->
   <template>
     <div>
       <el-button @click="showCreateDialog">新增用户</el-button>
       <el-table :data="userList">
         <el-table-column prop="username" label="用户名" />
         <el-table-column prop="email" label="邮箱" />
         <el-table-column label="操作">
           <template #default="{ row }">
             <el-button @click="showEditDialog(row)">编辑</el-button>
             <el-button @click="deleteUser(row.id)">删除</el-button>
           </template>
         </el-table-column>
       </el-table>
       <el-pagination
         :total="total"
         :page-size="pageSize"
         @current-change="handlePageChange"
       />
     </div>
   </template>
   
   <script setup>
   import { ref, onMounted } from 'vue'
   import { userApi } from '@/api/user'
   
   const userList = ref([])
   const total = ref(0)
   const pageSize = ref(20)
   
   const loadUsers = async (page = 1) => {
     const res = await userApi.list({ page, pageSize: pageSize.value })
     userList.value = res.data.records
     total.value = res.data.total
   }
   
   onMounted(() => {
     loadUsers()
   })
   </script>
   ```

6. **验证**：
   ```bash

   cd backend && mvn spring-boot:run
   
   # 启动前端
   cd frontend && npm run dev
   
   # 访问 http://localhost:5173/user/list
   # 测试功能:
   # ✅ 列表展示
   # ✅ 分页切换
   # ✅ 新增用户
   # ✅ 编辑用户
   # ✅ 删除用户
   ```

### 场景 2：带权限和审计的 CRUD

**TODO 中的功能**：
```markdown
- [ ] `DEPT-MANAGE` 部门管理；Owner: alice-chen
  - 目标: 管理员可以管理部门
  - 验收:
    - AC-001: 只有超级管理员可以操作
    - AC-002: 操作有审计日志
  - 交付面: data / api / backend / web / permission
```

**实施步骤**：

1. **权限注解**：
   ```java
   @RestController
   @RequestMapping("/api/v1/departments")
   @RequirePermission("dept:manage")
   public class DepartmentController {
       
       @PostMapping
       @RequireRole("SUPER_ADMIN")
       @Audit(action = "创建部门")
       public Result<Void> create(@RequestBody DeptDTO dto) {
           deptService.create(dto);
           return Result.ok();
       }
   }
   ```

2. **审计日志**：
   ```java
   @Service
   public class DepartmentService {
       
       @Autowired
       private AuditLogService auditLogService;
       
       @Transactional
       public void create(DeptDTO dto) {
           DeptEntity entity = convert(dto);
           deptMapper.insert(entity);
           
           // 记录审计日志
           auditLogService.log(
               "CREATE_DEPT",
               "创建部门: " + entity.getName(),
               getCurrentUser()
           );
       }
   }
   ```

3. **前端权限控制**：
   ```vue
   <template>
     <div>
       <el-button 
         v-if="hasPermission('dept:create')"
         @click="showCreateDialog"
       >
         新增部门
       </el-button>
     </div>
   </template>
   ```

## 关键规则

### 1. 纵向完整交付

```markdown
<!-- 正确: 纵向完整 -->
交付面: data / api / backend / web
→ Entity + Mapper + Service + Controller + Page

<!-- 错误: 只完成一层 -->
交付面: backend
→ 只写 Service，不写 Controller 和 Page
```

### 2. 真实前后端联动

```markdown
<!-- 正确: 真实调用 -->
前端页面调用真实 API
→ axios.get('/api/v1/users')
→ 显示真实数据

<!-- 错误: Mock 数据 -->
前端页面使用 Mock 数据
→ const users = [{ id: 1, name: 'test' }]
```

### 3. 适配项目规范

```bash
# 必须先发现项目规范
1. 语言、框架、ORM
2. 分层方式 (Controller → Service → Mapper)
3. 主键、审计字段、逻辑删除
4. 查询、分页、响应类型
5. 现有 CRUD 实现示例

# 再按规范实现
→ 复用现有基类
→ 复用现有工具类
→ 复用现有响应格式
```

### 4. 一次验证和 Review

```bash
# 完成全部交付面后
1. 启动后端
2. 启动前端
3. 测试所有 CRUD 操作
4. 一次 code-review
5. 提交代码
```
