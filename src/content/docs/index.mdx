本站包含两部分：Skills Framework 的安装与使用文档，以及 Docker、Linux、Java 的部署和运维参考。通过左侧主题菜单切换。

## Skills Framework

第一次使用，从[安装与配置](/skills/getting-started/)进入，完成后阅读[快速上手](/skills/quickstart/)。已有项目的开发、修复和交付步骤集中在[使用指南](/skills/usage/)。

| 你要做什么 | 阅读入口 |
| --- | --- |
| 了解文档内容与本次新增 Skill | [Skills 文档导览](/skills/) |
| 接入 Claude Code 或 Codex | [安装与配置](/skills/getting-started/) |
| 在当前项目开始使用 | [快速上手](/skills/quickstart/) |
| 完成一个功能 | [第一个功能开发](/skills/first-feature/) |
| 读取或接续 Claude Code、Codex 历史会话 | [历史会话接续](/skills/usage/session-resume/) |
| 按任务选择 Skill | [Skill 目录](/skills/catalog/) |
| 查询某个 Skill 的用法和边界 | [Skill 参考手册](/skills/skills-reference/) |
| 找不到 Skill、Hook 未生效或任务停住 | [故障排查](/skills/troubleshooting/) |

本站收录 **97 个框架 Skill**。Skill 由客户端原生发现和按需读取，Runtime Hook 提供行为约束、项目记忆与任务上下文；原理和维护资料见[核心概念](/skills/core-concepts/)与 [Runtime Hooks](/skills/hooks/)。
