## 30秒了解这个站点

**这是什么？** 两套独立的技术文档：

1. **Skills Framework**（主要内容）：95个 Skill + Runtime Hook，让 Claude Code/Codex 按固定流程写代码——自动路由 Skill、TODO 状态机、项目记忆、Git 交付门禁
2. **部署文档**（实操手册）：Docker/Linux/Java 的开箱即用配置，复制粘贴就能起服务

**适合谁？** 
- 想让 AI Agent 按规范干活的开发者 → 看 Skills Framework
- 需要快速部署服务的运维 → 看 Docker 部署

**从哪开始？**
- 新手：[5分钟快速上手](/skills/getting-started/) → [核心概念](/skills/core-concepts/)
- 老手：直接查 [Skill 参考手册](/skills/skills-reference/) 或 [按问题直接找](#按问题直接找)

## 使用建议

**Skills Framework 部分**：
- **新手路径**：[5分钟快速上手](/skills/getting-started/) → [核心概念](/skills/core-concepts/) → 试着用一次
- **熟练用户**：直接查 [Skill 参考手册](/skills/skills-reference/)，按需查触发词
- **遇到问题**：[故障排查](/skills/troubleshooting/) 有按症状分类的诊断命令

**部署部分**：按需查阅，每篇独立。看完就能执行，不需要先读其他篇章。

<Aside type="caution">
部署部分的命令带着写下来时的系统版本（CentOS 7/8、Ubuntu、树莓派），镜像地址和软件源会随时间失效。**照抄前先确认版本号和源地址是否还在**；命令顺序、参数含义和排错思路仍然有效。
</Aside>

## 站点结构

- **Java**：日志配置（logback-spring.xml），更多内容建设中
- **Linux**：建设中，目前相关内容散在 Docker 部分
